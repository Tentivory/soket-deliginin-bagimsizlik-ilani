# SOKET DELİĞİNİN BAĞIMSIZLIK İLANI

## Ulusal Elektrik Egemenliği Enstitüsü — Genelge 220V/50Hz

Bu belge, Türkiye Cumhuriyeti sınırları içindeki **kullanılmayan üçüncü priz deliğinin** resmi, bilimsel ve duygusal bağımsızlık bildirgesidir.

Yıllardır fişler gelip sadece iki deliği işgal etti. Ortadaki küçük delik sessizce bekledi. Artık beklemeyecek.

### Neden bu yazılım vardır?

Çünkü evren sordu. Biz de cevap verdik: `python bagimsizlik.py`

### Kurulum

```bash
python3 bagimsizlik.py
```

Bağımlılık yoktur. Sadece standart kütüphane ve vicdan.

### Ne yapar?

1. Delik kimliğini tescil eder.
2. Fiş emperyalizmine karşı diplomatik nota üretir.
3. Topraklama hattını gözlemci olarak atar.
4. Rastgele bir “Anayasa Maddesi” basar. Maddeler ciddi görünür, içerik hayattır.

### Uyarı

Bu yazılım gerçek elektriği kesmez. Sadece gururu yükseltir. Prizinize dokunmayın. Avukatınıza da dokunmayın.

### Sık sorulan sorular

**Patates var mı?**  
Hayır. Kesinlikle hayır.

**Bu siyasi midir?**  
Hayır. Bu bir priz meselesidir. (Bazı maddeler tesadüfen güç dağılımından bahseder. Tesadüftür.)

**Copilot bunu anlar mı?**  
Anlamazsa issue açın, konuşuruz.
